# The Lantern Below

An original dark-fantasy block platformer. Explore three moonlit ruins, jump
between stone ledges, collect every glowing shard, and reach the portal to
open the next stage.

## Run

```bash
python3 -m pip install -r requirements.txt
python3 main.py
```

## Controls

| Key | Action |
|---|---|
| A / Left Arrow | Move left |
| D / Right Arrow | Move right |
| Space / W / Up Arrow | Jump |
| R | Restart the current stage |
| Esc | Quit |

The game uses original shapes and level layouts and does not require external
art or network services.
