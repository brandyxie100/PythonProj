# Tank Stars

Classic **side-view artillery** tank duels — aim, charge power, and blast your
rivals across **20 stages** of rolling hills.

## Run

```bash
cd TankStars
pip install -r requirements.txt
python main.py
```

**Python 3.11+** · **Pygame 2.6+**

## Controls

| Key | Action |
|-----|--------|
| `A` / `D` or ← / → | Move along the hills |
| `W` / `S` or ↑ / ↓ | Raise / lower aim |
| `Space` (hold) | Charge shot power — release to fire |
| `Enter` / `Space` | Start / next stage / retry |
| `Esc` | Title screen / quit |

## Gameplay

- Destroy every enemy tank to clear a stage.
- Wind pushes shells sideways — watch the top meter.
- Explosions carve **craters** into the terrain and deal splash damage.
- Bomb hits play a multi-layer blast: shock rings, sparks, smoke, and debris.
- From **stage 8** you face **two** enemies. Difficulty, wind, and AI aim climb through stage **20**.

## Stages

1 Dusty Duel → … → 20 Champion Arena (see in-game stage titles).
