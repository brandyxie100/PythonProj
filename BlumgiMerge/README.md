# Blumgi Merge

Merge vivid slimes, auto-battle dungeon monsters, and clear **100 floors**.

Slime art includes CC0 sprites from OpenGameArt (nudelchef / Stendhal),
recolored into a bright candy palette with bounce, merge, attack, and coin FX.

## Run

```bash
cd BlumgiMerge
pip install -r requirements.txt
python main.py
```

## Controls

| Input | Action |
|-------|--------|
| Click **Buy Slime** | Spend gold for a tier-1 slime |
| Drag slime → matching slime | Merge into the next tier |
| Click **FIGHT!** | Send your army into the dungeon wave |
| Enter / Click | Start / continue after a result |
| Esc | Title / quit |

## Progression

- 10 slime tiers with unique colors and weapon accents
- Enemy HP/DPS ramp across floors 1–100
- Boss floors every 10 stages (extra HP + gold)
- Merge particles, idle bounce, attack lunge, hurt flash, coin popups
