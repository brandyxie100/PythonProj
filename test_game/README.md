# Spike Troll

A one-screen platformer that trolls you: **random spikes** flash yellow, then turn red and kill you.

## Run

```bash
cd test_game
pip install -r requirements.txt
python main.py
```

## Controls

| Key | Action |
|-----|--------|
| A / ← | Move left |
| D / → | Move right |
| ↑ (Up arrow) | Jump (Space / W also work) |
| R | Restart room |
| Esc | Quit |

## Goal

Reach the green **EXIT** through **10 levels** (Warmup → Almost Impossible).
Spikes spawn faster and warn shorter each room — level 10 is brutal but still beatable.
